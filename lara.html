Conexión con GitHub (una sola vez)
      
      
      
      
      
      
Crea un token en GitHub: Settings → Developer settings → Fine-grained tokens. Elige solo este repositorio y el permiso «Contents: Read and write», con vencimiento. Se guarda solo en este teléfono, igual que tu clave de Gemini. Lara guarda un respaldo de cada versión en la carpeta «respaldos» antes de publicar.

    

    
Respaldo de mis datos en GitHub (privado)
      
Guarda tus chats, memoria, notas y proyectos en un repositorio privado aparte (nunca en el público donde está la app). Créalo en GitHub, márcalo como Private y dale acceso a tu token con «Contents: Read and write». Si el repositorio es público, Lara se niega a guardar.
